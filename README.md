# FinSafe

Информационная система учёта личных финансов. Хранит транзакции по банковским счетам, бюджетные планы, финансовые цели и формирует аналитические отчёты.

## Состав репозитория

- README.md: описание проекта
- finsafe_db.sql: экспорт базы данных finsafe_db (MySQL)

## Развёртывание базы данных

1. Запустить Apache и MySQL в XAMPP.
2. В phpMyAdmin создать базу данных finsafe_db.
3. Выполнить импорт файла finsafe_db.sql.
4. Проверить, что у базы установлена кодировка utf8_general_ci, иначе кириллица в справочниках отобразится некорректно.

## Веб-интерфейс

Интерфейс написан на PHP и состоит из трёх блоков главного меню:

- Добавление данных: формы для пользователей, банков, категорий, счетов, операций, бюджетных планов и финансовых целей.
- Просмотр и управление данными: таблицы с кнопками "Редактировать" и "Удалить".
- Аналитика: расходы по категориям, динамика по месяцам, сравнение фактических трат с бюджетными планами.
