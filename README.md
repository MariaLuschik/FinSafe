# FinSafe

Информационная система учёта личных финансов. Хранит транзакции по банковским счетам, бюджетные планы, финансовые цели и формирует аналитические отчёты.

## Состав репозитория

- README.md: описание проекта
- finsafe_db.sql: экспорт базы данных finsafe_db (MySQL)

## Развёртывание базы данных

1. Запустить Apache и MySQL в XAMPP.
2. В phpMyAdmin создать базу данных finsafe_db.
3. Выполнить импорт файла finsafe_db.sql.
